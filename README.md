# PF03 - TDD con Node.js y CI

## Descripción

Este proyecto corresponde a la actividad PF03 del ciclo
formativo de Desarrollo de Aplicaciones Web (DAW).

El objetivo es desarrollar y probar dos funciones utilizando
la metodología Test Driven Development (TDD) con Node.js
y Vitest.

## Funcionalidades

- Cálculo de la sucesión de Fibonacci.
- Validación de códigos PIN.

## Tecnologías utilizadas

- Node.js
- JavaScript
- Vitest
- Git y GitHub
- GitHub Actions

## Metodología de trabajo

Se utilizará TDD siguiendo las tres fases:

1. RED: crear pruebas que inicialmente fallen.
2. GREEN: implementar el código para superar las pruebas.
3. REFACTOR: mejorar el código manteniendo las pruebas correctas.

## Ejecución de las pruebas

Instalar las dependencias:

    npm install

Ejecutar las pruebas:

    npm test
